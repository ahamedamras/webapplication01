### ⚙️ How My Portfolio Web Application Works

My personal portfolio is a responsive web application developed using HTML, CSS, and JavaScript. When a user opens the website, HTML displays the page structure and content, while CSS manages the design, layout, colours, and animations. JavaScript provides interactive features such as navigation and dynamic user interactions. Visitors can explore my profile, technical skills, and projects. They can also access my GitHub repositories to view source code and connect with me through LinkedIn. The website is designed to adapt to different screen sizes, including desktop computers, tablets, and mobile devices.
